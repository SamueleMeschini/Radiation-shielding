# Data provenance

Generation date: 2026-10-08. Python 3.13.14 and OpenMC 0.15.3 in the local `openmc-env` environment. The source manifest was an ENDF/B-VIII.1 NNDC HDF5 directory; its SHA-256 prefix is stored as `library_id` in each case and dataset. That library, its generated relative-path manifest, and the supporting Cu/Sn neutron HDF5 files are intentionally excluded from this repository because they are large external nuclear-data assets. Material composition identifiers are SHA-256 prefixes of composition, density, and name. Exact configuration files are `configs/materials.yaml`, `configs/simulation_grid.yaml`, `configs/sources.yaml`, and `configs/stacks.yaml` (JSON syntax, valid YAML). Case IDs hash the full case specification and library ID. Each case records random seed, histories, batches, electron treatment, and OpenMC version. The exported dataset also records SHA-256 hashes of each configuration file and of each case specification. The original prototype's 400-history data is preserved in `data/development/legacy_400_histories.json` and excluded from the new dashboard export.

Water mass fractions are retained from the prototype and agree with the [NIST XCOM water table](https://pml.nist.gov/PhysRefData/XrayMassCoef/ComTab/water.html). Concrete mass fractions and 2.30 g/cm³ density match [NIST STAR Concrete, Portland](https://physics.nist.gov/cgi-bin/Star/compos.pl?matno=144&mode=text); its composition was also retained from the prototype. Lead, copper, and tin are elemental. PMMA uses the [NIST Chemistry WebBook C5H8O2 formula](https://webbook.nist.gov/cgi/cbook.cgi?ID=C87210320), converted to mass fractions. Densities are teaching assumptions at 1.00, 2.30, 11.34, 1.19, 8.96, and 7.31 g/cm³ respectively. They are fixed in configuration; changes alter the composition ID.

[OpenMC photon-transport documentation](https://docs.openmc.org/en/stable/usersguide/settings.html#photon-transport) states that atomic relaxation is enabled by default and describes TTB versus LED. [NIST XCOM](https://physics.nist.gov/PhysRefData/Xcom/html/xcom1.html) is an independent attenuation reference. [NIST water](https://pml.nist.gov/PhysRefData/XrayMassCoef/ComTab/water.html) gives μ/ρ = 0.1707 cm²/g at 0.1 MeV and 0.07072 at 1 MeV; [NIST lead](https://pml.nist.gov/PhysRefData/XrayMassCoef/ElemTab/z82.html) gives 5.549 and 0.07102 cm²/g. These are total attenuation coefficients, not mass energy-absorption coefficients. Comparison to the OpenMC library is in tests/validation, allowing library differences.

The source presets use the specified line energies and equal photon weights for Co-60 solely for transport superposition. Absolute decay yields and activities are not used; source normalization is per emitted photon. No claim about Cs-137 beta branching is made. [NIST ESTAR](https://physics.nist.gov/PhysRefData/Star/Text/ESTAR.html) and [ASTAR](https://physics.nist.gov/PhysRefData/Star/Text/ASTAR.html) define the intended stopping-power sources, and their official text-only tables were retrieved on 2026-10-08 for the configured materials, except ASTAR concrete, which is unavailable in the selected NIST list. Raw HTML is retained in `data/reference/raw/`; parsed numeric rows, exact source URLs, and SHA-256 hashes are in `data/reference/stopping_powers.json`. Integration uses the first tabulated NIST CSDA range as a low-energy anchor. The lowest ESTAR energy is 0.01 MeV and the lowest ASTAR energy is 0.001 MeV; values outside the table are withheld.
